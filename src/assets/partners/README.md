# Partner logos

Upload each logo here, named after the partner's slug, and it appears on
/partners automatically. No code change needed.

| Partner | File name |
|---|---|
| Sunny Daze | `sunny-daze.svg` (or `.png`) |
| Jrew's | `jrews.svg` |
| Danu Social House | `danu-social-house.svg` |

New partners: add them to `productPartners` or `communityPartners` at the top
of `src/pages/partners.astro`, then upload `<slug>.svg` here.

- **SVG is best**, then a PNG at least 400px wide with a transparent background.
- Logos sit on a small white tile, so a dark logo on transparent works in both
  light and dark mode. A white logo will disappear: send the dark version.
- Use the partner's official file, not a screenshot.

Also: Heartwood Farm → `heartwood-farm.svg`, Sobrii → `sobrii.svg`.
